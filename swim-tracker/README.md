# Swim Tracker

選手コース管理ツール。運営: HYDOOR（ヒュドール）。担当: 長畑さん。

## 概要

選手のタイム管理・大会申し込み管理・練習記録を行うWeb/モバイルアプリ。
ターゲット：スイミング選手コース・高校大学水泳部。競合なし。

## 機能一覧（PDF より）

- 大会タイム管理：大会ごとのタイムを確認、目標タイムとの差分・過去結果の分析
- 大会申し込み管理：アプリ上で大会申し込み
- 練習記録：コーチ作成の練習を記録・サマリ化、後に分析
- 物販：HYDOORシステムと連携させたEC機能
- メディア：動画ブログ
