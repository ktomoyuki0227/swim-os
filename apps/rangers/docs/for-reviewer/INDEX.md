# Rangers レビューへようこそ

このたびは Rangers のリリース前最終チェックをお引き受けいただき、ありがとうございます。
このフォルダには、レビューを始める前に知っておいていただきたい情報をまとめています。

## まず知っておいてほしいこと

- 今回はコードベースを読んでいただく形のレビューです。実際に手を動かして試せる本番外の環境（テスト用Supabase/Stripe）は現時点でご用意していません。動作確認が必要な指摘は、仮説ベース（「〜という操作をすると、おそらく〜という状態になる」）で構いません
- 開発は生成AI（Claude Code）を主体に進めており、実装のたびにAIエージェントによる自己レビューを重ねてきました（計7回）。今回はその上で、人の目による独立した最終チェックをお願いしたいと考えています。AIによる自己レビューが見落としがちな観点を特に重視していただけると助かります（詳細は [RELEASE_REVIEW_BRIEF.md](./RELEASE_REVIEW_BRIEF.md) に記載）
- 本番の Supabase プロジェクトには実データ・実利用者が存在します。開発中のデモ環境ではありません

## 読まなくてよいもの

以下はリポジトリ内に存在しますが、今回のレビューでは読んでいただく必要はありません。

- `CLAUDE.md` — AI開発アシスタント（Claude Code）向けの内部指示
- `docs/MANUAL_OPERATIONS.md` — 開発者自身の手動運用チェックリスト。内容が一部古い
- `docs/reference/` 配下の画像類 — 開発中の参考スクリーンショット・動作確認用スクショ。`.gitignore` 対象なのでリポジトリには含まれていない
- `.env.local` 等の環境変数の実値、Supabase・Stripeの実キー — こちらは渡していません。必要な環境変数の一覧は `RELEASE_REVIEW_BRIEF.md` に記載しています

## レビューが終わったら

指摘事項は次の形式でまとめていただけると、対応の優先順位づけがしやすく助かります。

- 重大度: CRITICAL（致命的・即対応必須）/ HIGH（リリース前に対応すべき）/ MEDIUM（できれば対応）/ LOW（任意）
- 該当ファイル・行番号（わかる範囲でOK）
- 何が起きうるか（具体的な入力・操作でどう壊れるか）
- 可能であれば修正方針の提案

ご不明点・確認したいことがあれば、いつでもご連絡ください。
