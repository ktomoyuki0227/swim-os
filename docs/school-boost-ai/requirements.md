# SchoolBoost AI 要件定義

運営: HYDOOR（ヒュドール）

## 概要

育成級スイミングスクール向けの業務管理ツール。
煩雑な級の管理・月謝・予約・会員管理を一元化し、現場の工数を削減する。

競合: ペガサス・Hakomono・スコラプラス（乗り換えを促す差別化が重要）

---

## ステークホルダー

| 役割 | 説明 |
|------|------|
| スクール管理者 | スクール全体を管理するオーナー・マネージャー |
| コーチ・インストラクター | レッスンを担当し、欠席・振替を記録する |
| 保護者 | 子どもの出席状況・月謝・お知らせを確認する |
| 会員（子ども） | 授業を受ける生徒（保護者がアカウント管理） |

---

## 機能要件

### 0. マルチテナント（スクール管理）

- スクールごとにデータを完全分離（school_id による RLS 制御）
- 管理者がスクール専用の招待リンクを発行し、保護者を紐づける
- Phase 2〜：LINE 友だち追加で招待リンクを自動送信

### 1. 予約・スケジュール管理（コア機能）

#### 管理者・コーチ側
- クラス・レッスン枠の作成（曜日・時間・定員・担当コーチ・対象級）
- 欠席受付・管理
- 振替レッスンの割り当て・管理
- 出席確認（QRコード or 手入力）← 出席確認ページ自体は実装する。QRコードの運用方法（誰がどのデバイスで読み取るか）は未定・要後日確認

#### 保護者側
- 欠席連絡（アプリ or LINE から）
- 振替レッスンの検索・申し込み
- 出席履歴の確認

### 2. 月謝管理

#### 管理者側
- 会員ごとの月謝金額設定
- 支払い状況一覧（未払い・支払済みのステータス管理）
- 自動請求・決済（Stripe）
- 月次収支レポート

#### 保護者側
- 月謝の確認・オンライン決済
- 領収書ダウンロード

### 3. お知らせ配信

- お知らせ作成（管理者）
- プッシュ通知 + LINE通知 ← プッシュ通知は要後日確認（iOS対応が不安定なためLINE通知に一本化する案あり）
- クラス単位 or 全体への配信

### 4. Web申し込み（体験・入会）

- 体験レッスン申し込みフォーム（外部公開URL）
- 入会申し込みフォーム
- 申し込み管理ダッシュボード（管理者）
- 自動返信メール

### 5. 会員管理

- 会員情報登録（氏名・生年月日・保護者情報・緊急連絡先・健康情報）
- 会員一覧・検索・絞り込み
- 退会・休会処理
- 会員証発行（QRコード付き）

### 6. コミュニケーション機能

- スクール↔保護者間のチャット（管理者 ↔ 保護者 1対1）
- 既読確認

### 7. LINE連携

- LINEログイン（マイページへのアクセス）
- LINE Messaging API でお知らせ・月謝通知を送信
- 欠席連絡をLINEから受付

### 8. 位置情報管理（後フェーズ）

- 保護者のスマホで子どもの到着・退出を確認
- ジオフェンシングによる自動通知

### 9. 育成級管理（差別化ポイント）

- 級の定義・基準管理（何級に何ができるか）
- コーチが評価を登録
- 昇級時の通知・証明書発行
- 昇級アニメーション・ガミフィケーション演出（保護者・子ども向け）
- 昇級履歴の閲覧
- AI昇級推薦（出席率・評価履歴をもとにAIが次の昇級候補を提案）← AI機能・実装時期は後日確定

### 10. データ管理・分析

- ファネル管理（体験→入会→継続→退会の数値）
- クラス別稼働率
- 月別売上・入退会推移
- 退会理由集計

## 非機能要件

| 項目 | 要件 |
|------|------|
| 認証 | メール/パスワード + LINEログイン |
| ロール権限 | 管理者：全データアクセス可。コーチ：担当クラスのみアクセス可。保護者：自分の子どものデータのみ閲覧可 |
| セキュリティ | 子どもの個人情報を扱うため特に厳格に管理。HTTPS必須 |
| レスポンシブ | モバイルファースト（保護者はスマホ中心、管理者はPC中心） |
| パフォーマンス | LCP 2.5秒以内 |
| 多言語 | 日本語のみ（v1） |

## 保護者のスクール紐づけフロー

### PoC（基本形）
1. 管理者がスクール専用の招待リンクを発行
2. 保護者に手動で共有（メール・SMS・口頭など）
3. 保護者がリンクをタップ → LINE ログインまたはメールで登録 → 自動的にスクールに紐づく

### Phase 2〜（LINE自動化）
1. 保護者がスクールの LINE 公式アカウントを友だち追加
2. 友だち追加の Webhook をトリガーに招待リンクを LINE で自動送信
3. 保護者がリンクをタップ → LINE ログインで登録 → 自動紐づけ
4. 以降の通知・連絡もすべて LINE で自動化
