# SchoolBoost AI 競合分析

## 競合サービス比較

### スコラプラス（scholaplus）

- 導入実績: 1,200施設・利用者128万人以上
- 初期費用: 0円・更新料0円・会員数追加課金なし（業界最安水準）
- ターゲット: スイミング・体操・テニス・サッカー・塾・英会話など幅広い

#### 主要機能（15機能）
- 会員管理
- 予約・欠席・振替対応（スクール独自のルール設定に対応）
- レッスン管理
- 通知配信
- 電子チケット
- データ分析
- アンケート
- 体験申込受付
- 月謝管理・キャッシュレス決済
- 会員アプリ
- サポート対応（電話・メール・遠隔操作）
- 入退室管理
- 販売管理
- WEB入会
- バス位置情報配信

#### 強み
- 振替のルールを柔軟に設定できる
- 有人サポートが手厚い（電話・メール・遠隔操作）
- 実績が豊富で信頼性が高い

---

### hacomono（箱物）

- 導入実績: 10,000施設以上・継続率99%
- 開業導入率No.1
- 事務手続きを80%削減

#### 主要機能
- 予約管理（24時間オンライン予約・空き状況リアルタイム表示）
- 月謝・決済管理（クレジット・口座振替の自動引き落とし）
- 入退室管理（QRコード）
- LINE連携（1タップでマイページログイン）
- Web入会（紙不要・1分で完結）
- 会員管理（出席・購入・トレーニング履歴の一元管理）
- コミュニケーション（スタッフ↔会員のメッセージ機能）

#### 強み
- LINEとの連携が強力
- Web入会が1分で完結
- 幅広い業種（フィットネス・スポーツ・教育・コワーキング）に対応
- エンタープライズSaaS（クラウド型）

---

### ペガサス（PeGasus）

- 運営: 株式会社ネスティ（1983年創業・業界40年）
- 導入実績: 2,200施設以上
- 料金: 月額33,000円（定額制）＋ 初期費用別途
- サポート: 平均12分で解決・電話・メール・対面対応

#### 主要機能

| カテゴリ | 機能 |
|---------|------|
| フロント | 入退館、デジタル会員証、セルフチェックイン、POSレジ、バーコード決済、諸届変更 |
| スクール管理 | 振替予約、スクールバス振替・運行状況、進級テスト |
| 予約管理 | スタジオ予約、パーソナル予約、施設レンタル予約、チケット・回数券 |
| 会費請求 | 口座振替、クレジットカード決済 |
| タブレット | 入会受付、諸届変更、進級テスト、出欠確認 |
| WEBアプリ | 会員マイページ、諸届変更、イベント予約、振替予約、入会予約・決済 |
| 分析 | フリー帳票、データ集計、カスタム帳票、ダッシュボード |
| その他 | LINE連携、ゲート連携、24時間ジム対応、メール配信 |

#### 強み
- 業界40年の実績・信頼性
- サポートが手厚い（平均12分解決・電話・対面）
- 定額制で会員数が増えても料金固定
- オールインワン（フロント〜分析まで一気通貫）

#### 弱み
- 月額33,000円と高め（スコラプラスと比べてコスト高）
- 老舗ゆえにUI/UXが古い可能性あり

### SchoolBoost AI にしか「ない」機能（差別化）

| 機能 | 内容 | 効果 |
|------|------|------|
| 育成級ガミフィケーション | 昇級アニメーション・証明書発行・ワクワクする仕組み | 子ども・保護者の継続モチベーション向上 |
| AI機能（必ず実装） | 退会予兆検知・昇級推薦・お知らせ文章自動生成。「SchoolBoost AI」の名称の核 | 競合他社が持たない次世代機能。運営工数を削減 |
| スイミング特化設計 | 育成級の定義・評価基準をスイミング前提で設計 | 汎用ツールより設定が簡単 |
| Rangers との連携 | マスターズ・選手コースと同一プラットフォーム | SwimOS として一元管理へ |

### 価格戦略

競合（特にスコラプラス）が「初期費用0円」を強みにしている。
SchoolBoost AI は「無料トライアル期間」＋「移行サポート」で乗り換え障壁を下げる。

## PoCのMVPスコープ（競合調査を踏まえた優先度）

競合が持つ「当たり前機能」を最低限揃えることが乗り換え条件。

### 必須（PoC に入れる）
1. 会員管理（登録・一覧・検索）
2. クラス・スケジュール管理
3. 出席記録（欠席・振替）
4. 月謝管理（支払い状況確認）

### 重要だが後回し（Phase 1〜2）
5. Stripe 月謝決済
6. お知らせ配信
7. LINE連携
8. Web入会フォーム
9. 育成級管理（差別化機能）
10. データ分析ダッシュボード
