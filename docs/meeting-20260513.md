## 技術方針（共通）

### 統一する技術
- Next.js 15（App Router）
- Supabase（DB・Auth・Storage）
- Tailwind CSS + shadcn/ui
- Vercel（ホスティング）
- pnpm

### リポジトリ構成（要議論）

案A: モノレポ（turborepo）
```
swimos/
├── apps/
│   ├── rangers/
│   ├── school-boost/
│   ├── swim-tracker/
│   └── super-manager/
└── packages/
    ├── ui/          ← 共通コンポーネント
    ├── supabase/    ← Supabase クライアント・型
    └── stripe/      ← Stripe ユーティリティ
```

案B: 別リポジトリ（独立開発）
```
rangers/
school-boost/
swim-tracker/
super-manager/
```

→ 最終的に統合（SwimOS）するならモノレポが有利。ただし初期設定のコストあり。
→ 寺本さんの意見を聞きたいポイント。

### ブランチ戦略
- `main`：本番
- `develop`：開発統合
- `feature/xxx`：機能開発
