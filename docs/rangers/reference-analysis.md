# Rangers 参考サービス分析

## Dream Coaching（参考元）

URL: https://www.dream-coaching.com/
運営: 日本テレビ
一言: トップアスリートによるスポーツ個人指導・グループレッスン・イベントのプラットフォーム

---

## Dream Coaching の機能・UX分析

### レッスンの種類

| 種類 | 内容 |
|------|------|
| 個人指導 | 元日本代表・プロ選手が1対1で指導。好きな場所・時間で受講 |
| グループレッスン | 複数名で参加。個人指導よりリーズナブルに体験可能 |
| イベント | 日テレ主催の単発スポーツイベント。著名アスリートとの体験 |

### グループレッスンの表示項目（カードUI）

```
タイトル       : 【大人限定】基礎からもう一度！
日時           : 5月29日(金) 19:00 ～ 21:00
時間・料金     : 120分 / 9,000円
対象           : 大学生, 社会人・大人, シニア
募集期間       : 2026年4月7日 ～ 2026年5月28日 12:00まで
開催決定日     : 2026年5月27日(水) 12:00
開催場所       : ゆうぽうと世田谷レクセンター（住所も表示）
コーチ         : 大山未希（元バレーボール・ビーチバレーボール選手）
                 ★★★★★ 5.0（184件）
```

### ユーザー（スイマー）側の主な機能

- 無料会員登録
- 競技カテゴリー / コーチ名 で検索
- お気に入り登録
- 個人指導・グループレッスンそれぞれの予約履歴
- プロフィール編集（メール・電話・パスワード）
- クレジットカード登録
- チャット相談

### コーチ側の主な機能（推測）

- コーチプロフィール登録
- 個人指導・グループレッスンの作成・公開
- 予約管理
- 新規参加コーチ向けクーポン（2,000円クーポン）

### レビュー・評価システム

- ★5段階評価 + テキストレビュー
- 件数表示（例：5.0 / 184件）
- ネガティブなレビューも掲載（透明性あり）

### 収益モデル（推測）

- ユーザーがレッスン料を支払い → プラットフォームが手数料を引いてコーチに支払う
- Stripe Connect モデルと類似

## Rangers との比較・差別化

| 項目 | Dream Coaching | Rangers |
|------|---------------|---------|
| 対象スポーツ | 全スポーツ（水泳・かけっこ・野球など） | 水泳特化 |
| ターゲットユーザー | 一般（キッズ〜大人） | マスターズ水泳・個人指導員 |
| コーチ層 | 元日本代表・プロ選手 | 個人指導員（プロ〜上級者） |
| 運営 | 日テレ（大企業） | HYDOOR（ヒュドール） |
| 競合状況 | 競合あり | 水泳マスターズ特化では競合なし |

### Rangers が参考にすべき点

1. グループレッスンのカードUI（日時・時間・料金・対象・場所・コーチ評価を一覧表示）
2. コーチ評価・レビューシステム（透明性のある評価で信頼構築）
3. 個人指導 + グループレッスン の2種類のレッスン形式
4. 無料会員登録 → クレジットカード登録 → 予約・決済 のフロー
5. お気に入り機能 + 予約履歴で継続利用を促す

### Rangers が差別化できる点

1. 水泳・マスターズに特化した検索（種目・距離・技術レベルで絞り込み）
2. Swim Tracker・SchoolBoost との統合（SwimOS内でデータ連携）
3. チーム管理・月謝管理（Dream Coaching にはない）

## Dream Coaching の UXフロー（Rangers の参考実装）

```
[スイマー]
① トップ → 水泳カテゴリーを選択
② レッスン一覧 → 日時・料金・場所・コーチで絞り込み
③ レッスン詳細 → コーチプロフィール・評価・空き状況確認
④ 予約確認 → クレジットカード決済（Stripe）
⑤ 予約完了 → メール通知 + マイページに記録

[指導員]
① コーチ登録 → プロフィール・実績・資格を入力
② レッスン作成 → 種類（個人 or グループ）・日時・料金・定員・場所を設定
③ レッスン公開
④ 予約通知を受け取る
⑤ ダッシュボードで売上・予約状況を確認
⑥ Stripe Connect で売上を受け取る
```
