# Rangers 要件定義

運営: HYDOOR（ヒュドール）

## 概要

マスターズ水泳・個人指導員向けの予約・管理プラットフォーム。
スイマーが単発レッスンを検索・予約・決済し、指導員がレッスンを管理できる。

競合なし。ユーザー獲得しやすい領域。

---

## ステークホルダー

| 役割 | 説明 |
|------|------|
| スイマー | マスターズ会員。レッスンを探して予約・決済する |
| 指導員（個人） | レッスンを作成・管理し、収益を受け取る |
| チーム管理者 | 複数スイマーのチームを束ねる（コーチ兼任可） |
| システム管理者 | プラットフォーム全体の管理 |

---

## 機能要件

### 1. 単発レッスン予約・決済（コア機能）

#### スイマー側
- レッスン一覧の検索・フィルタリング（日時・場所・指導員・種目）
- レッスン詳細の閲覧
- レッスン予約（空き確認）
- Stripe 決済（クレジットカード・Apple Pay・Google Pay）
- 予約確認・キャンセル
- 予約履歴の閲覧

#### 指導員側
- レッスン作成（タイトル・日時・定員・料金・場所・説明・画像）
- レッスンの編集・削除
- 予約者一覧の確認
- レッスンのキャンセル通知
- 売上ダッシュボード（日別・月別・累計）
- 振込管理（Stripe Connect）← Phase 1〜（PoCスコープ外）

### 2. チーム管理

PoC後半に着手（コア機能完成後）。時間がなければ切る。

- チーム作成・招待（QRコード or 招待リンク）
- チームメンバー管理（追加・削除）
- チーム向けレッスン予約管理
- 月謝管理（金額設定・支払い状況管理）← Phase 2〜
- 月謝の自動請求・決済（Stripe）← Phase 2〜

### 3. 物販（後フェーズ）

- HYDOORシステムとのEC連携
- 商品一覧・カート・購入フロー

### 4. メディア（後フェーズ）

- 動画・ブログ投稿（指導員側）
- コンテンツ閲覧（スイマー側）
- 動画ストリーミング（Supabase Storage）

---

## 非機能要件

| 項目 | 要件 |
|------|------|
| 認証 | メール/パスワード + Google OAuth |
| セキュリティ | HTTPS必須、決済はStripeに委任（PCI DSS準拠） |
| レスポンシブ | モバイルファースト（マスターズユーザーはスマホ中心） |
| パフォーマンス | LCP 2.5秒以内 |
| 多言語 | 日本語のみ（v1） |

---

## 画面一覧（MVP）

### スイマー向け
1. トップ / レッスン検索
2. レッスン詳細
3. 予約確認・決済
4. マイページ（予約履歴・プロフィール）
5. チーム詳細 ← 低優先度（PoC後半・チーム管理が間に合えば）

### 指導員向け
1. ダッシュボード（売上・予約数サマリ）
2. レッスン管理一覧
3. レッスン作成・編集
4. 予約者管理
5. 月謝管理 ← Phase 2〜（PoCスコープ外）

### 共通
1. ログイン / 会員登録
2. プロフィール設定
